# Distribution channels

Where promptguard reaches its users, in launch order:

1. **pub.dev** — `dart pub global activate promptguard` is the install path;
   the pub.dev page links back here with the full README.
2. **GitHub** — this repo; the workflow file in `distribution/` is what
   people copy-paste into their apps.
3. **Show HN / r/dartlang / r/FlutterDev / X** — announce with the
   "silent regression" story (see `distribution/announce.md`).
4. **Marketplace listing** — the GitHub Action YAML doubles as an
   Action Marketplace submission once wrapped (roadmap v0.2).
